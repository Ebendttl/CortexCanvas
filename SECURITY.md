# Security Policy

## Supported Versions

Only the latest stable version of CortexCanvas is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

We take the security of CortexCanvas seriously. If you believe you have found a security vulnerability, please do **not** open a public issue.

Instead, please follow these steps:
1. Send an email to **security@cortexcanvas.ai** with details of the vulnerability.
2. Include a proof of concept (PoC) if possible.
3. We will acknowledge your report within 48 hours.

## Our Responsibility

- We will provide a fix or mitigation plan as soon as possible.
- We will keep you updated on the progress.
- We will give credit to the reporter in our security advisories (unless you wish to remain anonymous).

*Thank you for helping keep CortexCanvas secure!*
